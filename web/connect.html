这台服务器已安装常驻服务。本页只负责一次性绑定：完成后凭据交给常驻服务长期保存（仅本用户可读的 0600 文件），由它负责断线重连、开机自启和来信自动唤醒 dot。以后凭据失效时，再运行一次本程序即可重新授权，消息和订阅保留。

使用腾讯官方 SDK 扫码连接；手机页面显示“第三方机器人”。请选自己管理的机器人，确认后凭据只留本次进程内存。QQ 机器人控制台

无需微信 AppID 或 AppSecret。填好下方 Tunnel 信息后点连接，再用本人微信扫描官方二维码并确认；是否能绑定以微信提示为准。

连接已有 dot 的私人 Tunnel

常驻服务已保存 Tunnel 配置：三项都留空即沿用；要更换时三项都填写。

使用与原 dot 对应的账号和组织。缺少通道时打开 Tunnel 页面，按 官方说明准备私人通道；连接后还需接入原 dot 的私人插件。

密钥只从官方页面复制到这里，不发给聊天或 Agent。创建资源前先确认账号、权限和用途；不需要模型 API 权限。
